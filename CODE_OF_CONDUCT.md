# Code of conduct

This is a small project in a friendly community, and we want it to stay that way.

- Be respectful and patient, especially with people new to modding or to GitHub.
- Criticize ideas and code, never people.
- No harassment, discrimination, or personal attacks.
- Assume good intent; ask before assuming otherwise.

If someone is not following this, report it by opening a private security advisory on the repository or by contacting the maintainer through their GitHub profile. Maintainers may edit, hide or remove comments, issues and contributions that break these rules, and may block repeat offenders.
