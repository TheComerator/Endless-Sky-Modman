# Contributing

Thanks for wanting to help. Small contributions matter here: a clear bug report, a tested Linux or macOS install, a typo fix.

## The most useful things right now

1. **Try it and tell us what happened**, especially on Linux and macOS, and with unusual setups (Flatpak Steam, AppImage, custom config folders).
2. **Report plugins that are misread**: wrong dependencies, wrong conflicts, odd names.
3. **Suggest ideas**, but please open an issue first so we can talk before you build something big.

## Reporting a bug

Use the issue form. Include what you did, what you expected, what happened, your system, and the relevant lines of the log (the file is in `logs\` under the app's local data folder; see the README).

## Changing the code

The project is a Rust core library (`crates/esmm-core`, no UI dependencies), a Tauri shell (`app/src-tauri`) and a React + TypeScript interface (`app/src`). [CLAUDE.md](CLAUDE.md) records how and why it's built this way; skim the part you're touching.

Before opening a pull request, from the repository root:

```bash
cargo fmt --check
cargo clippy --all-targets
cargo test -p esmm-core
cd app && npm run build && npm test
```

Notes:
- Add or update a test for behavior you change. Most logic lives in `esmm-core` and is tested there with fake downloads, so no network is needed.
- `cargo test -p esmm` (the Tauri shell's own tests) can't run on Windows because of an OS manifest limitation; it runs on Linux. If you change that crate on Windows, say so in the PR.
- If you change a type that crosses to the UI, the TypeScript bindings in `app/src/bindings/` are generated by `cargo test` and committed.
- Keep pull requests small and focused. A short description of *why* helps more than a long one of *what*.
