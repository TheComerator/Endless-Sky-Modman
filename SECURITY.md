# Security

The app downloads and unpacks plugin archives and edits files the game reads, so security reports are taken seriously.

**Please don't post a vulnerability in a public issue.** Use GitHub's "Report a vulnerability" (private security advisory) on this repository's Security tab.

Useful details: what you did, what happened, the app version, and your system. Examples of what we care about: a way for a crafted plugin archive to write outside its folder, a way to bypass the HTTPS-only rule, or anything that makes the app delete files it shouldn't.

This is a volunteer project, so replies may take a few days.
